## 💻 Tech Stack & Frontend Architecture

This repository contains the standalone, open-source frontend for [leiosroadrunner.xyz](https://leiosroadrunner.xyz).

* **HTML5 & CSS3:** Semantic structure with responsive viewport scaling.
* **Tailwind CSS (CDN):** Modern utility-first styling with custom dark-mode theme palettes (`snekdark`, `cyan`, `gold`, `crimson`).
* **FontAwesome v6 & Inline SVG:** Scalable vector icons for clean rendering across all mobile browsers and desktop clients.
* **JavaScript (Vanilla ES6):** Lightweight client-side calculations (Swap Calculator) and interactive animations without heavy framework overhead.
* **Continuous Deployment:** Hosted on **Netlify** with automatic git-push deployments directly from the `main` branch.
